# PulseFour

Four-bar live pulse desk for bedroom producers and AI-music finishers.

Static loops stall because nothing drives them. Session players write four live bars of pulse — upright on the quarters, piano accents, kit on the pulse — so the pocket has drive and the track can finish.

Live samples only — FluidR3 acoustic grand, upright bass, nylon guitar, trumpet, violin, and acoustic kit from the PreEight sample CDN pinned to commit `d58301e4a494555f411a2afbc448b724136eee76`.

No oscillators. Audio never leaves the tab.
